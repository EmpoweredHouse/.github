# Security policy

This policy applies to every public repository of the EmpoweredHouse organization, unless a repository has its own SECURITY.md.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Email **contact@empowered.house** with "Security" in the subject line. Include:

- the repository and version or commit
- what you found and how to reproduce it
- the impact you expect

We read every report and reply to the address you write from. Please give us a reasonable time to fix the problem before you disclose it publicly.

## Supported versions

Fixes go to the latest version on the main branch of each repository.
