# Contributing

Thank you for your interest. This guide applies to every public repository of the EmpoweredHouse organization, unless a repository has its own CONTRIBUTING.md.

## Issues

Open an issue to report a bug or suggest a change. Describe what you expected, what happened, and how to reproduce it.

## Pull requests

- For a small fix, open a pull request directly.
- For a larger change, open an issue first, so we can agree on the approach before you spend time on it.
- Keep each pull request to 1 change, with a short description of why it is needed.

## Licence

Each repository states its own licence. By contributing, you agree that your contribution is released under that licence.

## Security

Do not report security problems in issues. See [SECURITY.md](https://github.com/EmpoweredHouse/.github/blob/main/SECURITY.md).
